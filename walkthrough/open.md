# Open an RTF file

Click a `.rtf` file in the Explorer. It opens as a read-only page with the fonts, colors, tables and pictures of the file.

- Open as Text (top right) shows the RTF source in the normal editor.
- View switches between Page (the width and margins of the document) and Flow (the width of the editor).
- Page colors: Auto follows your VS Code theme. Light, Dark and Invert are always there.

When the file changes on disk, for example when R or SAS writes a table again, the view reloads and keeps its place.
