# Changelog

## 0.1.0

- First release. Opens .rtf files as a read-only page with tables (merged cells, borders, shading), pictures (PNG, JPEG, EMF, WMF, BMP), headers and footers, footnotes, code pages and Unicode.
- Search, outline, zoom, Page and Flow views, Auto, Light, Dark and Invert page colors.
- Live reload when the file changes on disk. Copy all text, export as HTML, Open as Text.
- Large files are read in a background thread and shown while they load.
- Embedded objects are shown as a box and never opened; only web and mail links open, after a click.
